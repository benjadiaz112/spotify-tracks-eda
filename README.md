## Resultados de EP3

El HGB ajustado obtuvo un MAE de **5,02 puntos**, RMSE de **8,50** y R² de **0,830** sobre 17.913 canciones de reserva. El **91,97 %** de las predicciones quedó dentro de ±15 puntos de popularidad. El criterio de selección fue el menor MAE medio en cinco folds agrupados de desarrollo.
